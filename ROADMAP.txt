[x] Provider Semantic Scholar (4a fonte)
    Novo src/providers/semanticscholar.py via Graph API (paper/search,
    fields=title,year,abstract,authors,venue,externalIds,citationCount,
    openAccessPdf,publicationTypes,journal). Chave opcional
    SEMANTIC_SCHOLAR_API_KEY (header x-api-key); sem chave usa tier anonimo.
    Resiliencia: ssl via utils.http_get, sleep 0.2s antes da request e
    soft-fail (retorna []) em HTTP 429. venue_type normalizado a partir de
    publicationTypes; publisher/concepts ficam None por ora.
    Integrado em cli.py e web.py (_search_all + _PROVIDER_NAMES + _ALL_SOURCES)
    e em ranking.SOURCE_WEIGHTS ("semanticscholar": 0.85). .env.example atualizado.

[x] Rework do limite — cap no total, nao por-provedor
    Sintoma: buscar 10 retornava 200. Causa: web._fetch buscava max(limit*4,200)
    por provedor e o rotulo "N de M" exibia o pool inteiro. Fix: ambos os
    orquestradores buscam min(limit*3,100) candidatos por provedor; pipeline
    fetch -> dedup -> rank -> filtros -> truncar em limit. CLI alinhado ao web.

[x] Remocao da paginacao "carregar mais"
    SUPERSEDE o item [x] "Paginacao / carregar mais" de 2026-05-09.
    display_limit, "Mostrar mais" e "Recolher" removidos. O slider de limite
    agora e o teto direto da lista exibida (re-fatia o pool ja buscado ao
    arrastar, sem nova chamada a API).

[x] Rotulo de contagem corrigido + falhas de provedor sempre visiveis
    Antes mostrava "10 de 200" (enganoso). Agora: "N artigo(s) encontrados,
    R candidato(s) avaliado(s), D duplicata(s) removida(s)" em busca fresca;
    so "N artigo(s) encontrados (cache)" em cache hit. Aviso de provedores
    indisponiveis saiu do else de "if not sliced" — uma queda total nao se
    disfarca mais de "nenhum resultado para os filtros".

[x] Fix StreamlitAPIException no botao de busca recente
    Atribuir st.session_state.query_input apos instanciar o widget quebrava.
    Agora usa callback on_click (_set_query_from_recent) + key pre-inicializada.

[x] Docs: ROADMAP.txt agora e a fonte unica do roadmap
    CLAUDE.md aponta para este arquivo no topo ("ler antes de qualquer task")
    e nao duplica mais o roadmap. CLAUDE.md tambem corrigido: comando CLI usa
    subcomando `main`, e a suite de testes (pytest) passou a ser documentada.

    `try/except Exception: pass` em volta do `_app()` engolia bugs reais.
    Substituido por `try/except ImportError` em volta apenas do import — erros

[x] Fix Elsevier 100% sem abstract (2026-05-09)
    Provider nao passava view=COMPLETE na requisicao. View padrao STANDARD
    nao inclui dc:description (abstract). Resultado: 100% dos artigos da
    Elsevier vinham sem abstract, degradando ranking semantico, exportacao
    BibTeX e UI. Apos fix: 0% sem abstract (vs 36% no OpenAlex, esperado).

[x] Renomear cache.set -> cache.store (2026-05-09)
    A funcao publica `def set(query, articles)` em cache.py shadowa o builtin
    `set()` em todo o modulo, quebrando qualquer chamada interna a set(rows).
    Renomeada para `cache.store()`. Atualizado cli.py, web.py, tests/test_cache.py.

[x] Fix Article.__hash__/__eq__ nao normalizavam DOI (2026-05-09)
    Mesmo bug que dedup_articles tinha — OpenAlex retorna DOI com prefixo,
    Elsevier retorna bare. Article posto em set/dict nao deduplicava
    corretamente. Tambem: __eq__ nao verificava isinstance, gerando
    AttributeError ao comparar com nao-Article. Adicionado _norm_doi local
    em models.py (mirror de utils._normalize_doi para evitar import circular).

    P5 — Detectar papers retratados (Retraction Watch): novo modulo
