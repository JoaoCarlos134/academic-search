[x] Cache limit-aware
    Busca com limit=10 cacheia 10. Pedido posterior com limit=30 retornava
    apenas 10. Fix: sempre buscar/armazenar com um teto maior (CACHE_FETCH_LIMIT=50)
    e fatiar na leitura. Se limit pedido excede o cache, invalida e refaz.

[x] Melhor UI de erro por provedor
    Exibir a mensagem real do erro (ex: "401 Unauthorized") por provider,
    nao apenas o nome. Guardado em session_state.provider_errors como dict.

[x] Filtros na pagina de busca
    Filtrar resultados por: intervalo de ano, tipo de publicacao
    (journal/conference/book/other), fonte (openalex/elsevier/ieee),
    e open access. Todos os campos ja existem no Article.

ALTA PRIORIDADE

[ ] Persistir embeddings no SQLite
    Hoje _embedding_cache em ranking.py e dict em memoria — perdido ao
    reiniciar o processo Streamlit. Persistir vetores por DOI no SQLite
    elimina re-encoding entre sessoes. Cada vetor ~1.5KB (384 floats float32).
    Adicionar coluna `embedding` (BLOB ou TEXT JSON) na tabela article_cache,
    ou criar tabela dedicada `article_embeddings(doi, vec)`.

[ ] Filtros pre-busca uniformes entre CLI e Web
    Web tem source filter pre-busca (skip provider) + year/oa/type pos-busca.
    CLI tem todos pos-busca. Uniformizar: ambos com source pre-busca.
    Source na CLI deve impedir chamada ao provider excluido (ja existe a
    logica em web._search_all com sources=set; replicar em cli._search_all).

[ ] Historico de buscas na Web
    Cache ja guarda queries recentes. Expor como dropdown/lista no Streamlit
    com as ultimas 10 queries (ordenadas por cached_at desc). Click preenche
    o input. Util para retomar trabalho. Funcao auxiliar nova em cache.py:
    list_recent_queries(limit=10) -> list[str].

[ ] Botao "Atualizar" forcando re-fetch na Web
    Hoje so existe `search clear-cache` no CLI. Na Web, o usuario nao tem
    como invalidar manualmente o cache de uma query. Adicionar botao
    "Atualizar resultados" ao lado do "Buscar" que faz cache.invalidate(query)
    + nova busca. Funcao nova em cache.py: invalidate(query) -> int.

[ ] Detectar papers retratados via Crossref Retraction Watch
    A API publica https://api.labs.crossref.org/data/retractionwatch retorna
    DOIs retratados. Marcar artigos retratados com badge vermelho na UI e
    flag no Article (retracted: bool | None). Importante para integridade
    academica. Pode ser checado em batch apos o fetch (uma chamada por busca,

[ ] Agrupamento por topico usando embeddings
    Usar os embeddings ja calculados (sentence-transformers) para clusterizar
    resultados via k-means simples (sklearn ou scipy). UI mostra resultados
    agrupados por cluster com label inferido (top palavras dos titulos do
    cluster). Util para buscas amplas onde o pool tem subtemas distintos.

[ ] Renovar IEEE API key
    IEEE_API_KEY esta vazia no .env. Provider funciona mas retorna lista

    Sem chave, o filtro de fonte na UI mostra "ieee" mas nunca traz resultados.

DESCARTADAS

[~] Resumos em portugues via Anthropic Haiku
    Avaliado: traduzir/resumir abstracts em portugues sob demanda.
    Custo estimado: ~$0.005 por sessao tipica (com cache + sob demanda).
    Decisao: descartado. Justificativa principal ("maior parte dos artigos
    sem resumo") deixou de valer apos fix do view=COMPLETE no Elsevier
    (passou de 100% sem abstract para 0%). OpenAlex ainda tem 36% sem
    abstract mas LLM nao tem o conteudo do paper para gerar resumo
    confiavel — risco de hallucination. Reavaliar se a equipe quiser
    traducao automatica de abstracts em ingles para portugues.

    `try/except Exception: pass` em volta do `_app()` engolia bugs reais.

[x] Fix Elsevier 100% sem abstract (2026-05-09)
    Provider nao passava view=COMPLETE na requisicao. View padrao STANDARD
    nao inclui dc:description (abstract). Resultado: 100% dos artigos da
    Elsevier vinham sem abstract, degradando ranking semantico, exportacao
    BibTeX e UI. Apos fix: 0% sem abstract (vs 36% no OpenAlex, esperado).

[x] Renomear cache.set -> cache.store (2026-05-09)
    A funcao publica `def set(query, articles)` em cache.py shadowa o builtin
    `set()` em todo o modulo, quebrando qualquer chamada interna a set(rows).
    Renomeada para `cache.store()`. Atualizado cli.py, web.py, tests/test_cache.py.

[x] Fix Article.__hash__/__eq__ nao normalizavam DOI (2026-05-09)
    Mesmo bug que dedup_articles tinha — OpenAlex retorna DOI com prefixo,
    Elsevier retorna bare. Article posto em set/dict nao deduplicava
    corretamente. Tambem: __eq__ nao verificava isinstance, gerando
    AttributeError ao comparar com nao-Article. Adicionado _norm_doi local
    em models.py (mirror de utils._normalize_doi para evitar import circular).
